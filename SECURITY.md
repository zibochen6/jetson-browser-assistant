# Security

This is a local desktop prototype. Its control APIs have no authentication and
must stay on127.0.0.1. Do not expose ports8790–8793 or run the project as root.
A hostile webpage can contain misleading text; constrained candidates and guards
are not a general prompt-injection defense. Keep human oversight and independent
checks, and don't extend the demo to payments or safety-critical control unchecked.

Model/wrapper revisions are pinned and weights are checksum-verified. Review
upstream executable model code before trusting it. Downloads reject invalid size,
checksum and HTML responses; the pinned checksums are not publisher signatures.

Please report vulnerabilities through GitHub's private vulnerability reporting
when available, rather than posting credentials or private task/browser records in
an issue. For ordinary bugs use the issue template with redacted logs and versions.
